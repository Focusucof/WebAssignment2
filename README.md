## Pages

| Route | View | Purpose |
|---|---|---|
| `/` | `views/index.ejs` | Home page with my social links |
| `/about` | `views/about.ejs` | About me |
| `/projects` | `views/projects.ejs` | Personal projects with links to them |

## Project Structure

Generated with the Express Generator using the `--view=ejs` option.

```
app.js            (sets up Express, the EJS view engine and the routes)
bin/www           (starts the server)
routes/           (one router file per page)
views/            (EJS page templates)
  components/     (partials shared between pages)
public/
  images/         (profile photo, project logos, home page background)
  stylesheets/    (style.css)
  javascripts/
README.md
```

## Routes

Each route is stored in its own file in routes/ for simplicity and readability. Each file handles its respective route handling and setting the title variable used in that template. The projects route handler also has an object holding all the content for the projects that are shown on the projects page to reduce code duplication. These are rendered with a JS foreach loop.

| File | Path | What it does |
|---|---|---|
| `routes/index.js` | `/` | Serves `index.ejs` with the page title |
| `routes/about.js` | `/about` | Serves `about.ejs` with the page title |
| `routes/projects.js` | `/projects` | Holds the list of projects and passes it to `projects.ejs` |
| `routes/contact.js` | `/contact` | Serves `contact.ejs` with the page title |

## EJS Templates and Partials

Every page is built from the same partials so the header, navbar and footer are shared across the site.

| Partial | Where I used it | Why |
|---|---|---|
| `components/head.ejs` | Top of all four pages | Holds the page title and the stylesheet links so they are only written once |
| `components/navbar.ejs` | All four pages | The navigation links for the site |
| `components/footer.ejs` | Bottom of all four pages | Copyright notice, email and social links. Takes a `socials` option so the home page can hide the buttons |
| `components/social-buttons.ejs` | Home page and the footer | GitHub and LinkedIn buttons |

## Bootstrap and Font Awesome

- **Bootstrap 5.3.3:** used for the layout (container, rows and columns), spacing and text utilities, borders and the contact form. Since I'm used to using the Tailwind CSS framework, using Bootstrap was also very familiar and allowed me to upgrade the visuals of this site compared to assignment 1
- **Font Awesome 6.5.2:** the GitHub and LinkedIn icons on the social buttons, the arrow on each project card and the paper plane on the Send button.
- **My own CSS:** `public/stylesheets/style.css` holds the styles that are not included in Bootstrap and are crucial to this specific styling.

## Contact Form Validation

The form uses HTML5 validation for each field:

- `required` on name, email, phone and message
- `type="email"` to check the email format
- `type="tel"` for the phone number
- `maxlength="500"` on the message
- `action="mailto:..."` with `method="post"` and `enctype="text/plain"` to send the form through an email client
